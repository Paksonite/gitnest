# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in GitNest,
please report it privately rather than opening a public issue.

Use GitHub's private vulnerability reporting feature
if it is enabled for this repository.

Please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- The potential impact.
- Any relevant logs or proof of concept.

Please do not include secrets, access tokens,
or private repository contents in your report.

## Supported Versions

Security fixes are provided for the latest stable release.
